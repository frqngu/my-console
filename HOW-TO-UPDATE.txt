CONSOLE UPDATE v1267

WHAT IT CHANGES
  - Install progress: a download bar under the button with downloaded of total, percent, speed and time left (Steam exact; Epic, Ubisoft, EA estimated)
  - Epic games in C:\\Users\\you\\Epic Games are found
  - Epic games installed on disk but missing from Epic record files (new Epic launcher) are found by their folder
  - A game you pressed Install on is followed in the background, so a finished install is noticed even if you left the game page
  - Epic Games installs: the button follows the download (Installing %) instead of staying on Confirm install
  - Library: removing a game keeps your place in the list (no jump to the top)
  - Library: the right-hand panel updates in place, so it no longer flickers when you move between games
  - Real console notification pop-ups (slide in top right with a chime, also saved in Control Center > Notifications): update available, update complete, installation complete, game library complete, game info/box art/trailers finished, signed in
  - Games that failed to load info before get one automatic retry
  - Setup guide Spotify step now has Premium steps and a skip option
  - Smoother PS5 intro (no dark dip around 10 seconds)
  - Keyboard Enter/Space or a mouse click gets you past the PS start screen if the PS button does not respond
  - Wallpaper music mutes while Spotify is playing in the console
  - Release Year now shows the year (it showed "Feb" before)
  - Spotify in the Music card: play/pause, next and previous buttons, with song and artist, no Spotify sign-in needed
  - Settings has a new "Spotify (cover art and controls)" row where you enter your Client ID and sign in
  - Sound card: Menu sounds and Console music bars move with the stick (left/right), hold to go faster
  - Games & library settings: the two IGDB rows are gone (not needed); the remaining key rows say what each one is for
  - Ubisoft sign-in: the instructions are a small window on the second monitor and the Ubisoft page opens there too; the console no longer jumps back in front
  - Game name art: if Steam/Epic/GOG have no logo for a game and you set a SteamGridDB key, the logo comes from SteamGridDB
  - NEW: a Setup guide checklist window opens on the second monitor about 20 seconds after the first launch and closes itself when every box is ticked (also under Settings > Games & library > Setup guide)
  - FIX: a fresh install now asks for the name and picture (it used to skip it and show "Frankie")
  - FIX: "Tom Clancy's" games (Ghost Recon Breakpoint and Wildlands) now match their store pages, so they get cover art, name art, and description/year/developer
  - Launcher games that are also on Steam (Ubisoft, EA...) now get their description, year, developer and publisher from the Steam page with no key
  - Prime Video and Disney+ show their logo instead of plain text

HOW TO UPLOAD ON GITHUB.COM (no GitHub Desktop needed)
  1. Extract this zip first.
  2. Open github.com/frqngu/my-console and sign in.
  3. Click Add file, then Upload files.
  4. Open the extracted folder and drag everything inside it (main.js, preload.js, guide-preload.js, renderer, logos) onto the page. Do not drag the folder named console-update-v1267 itself.
  5. Scroll down, type "update v1267", and click Commit changes.
  6. Click Actions, then Build Windows installer, then Run workflow.
  7. When the green tick appears, download My-Console-Setup.exe from your link and install it.
